

# Curso Desarrollo Frontend I 
# Semana 3 - Primera Actividad Sumativa "Construyendo un sitio web básico"

# Contexto 

Proyecto correspondiente a la primera actividad sumativa del Curso Desarrollo Frontend I (semana 3)

Se implementa una página web para una tienda de video juegos denominada "Tienda William Wallace", donde se ponen en práctica los conocimientos adquiridos respecto a la optimización de un sitio web básico. 

# Objetivo

La actividad se centra en mejorar la apariencia visual utilizando el modelo de cajas, colores, tipografías y selectores CSS. Además, se emplearán Flexbox y CSS Grid para organizar la disposición de los elementos de manera adaptable. 

# Estructura del Proyecto
Árbol de carpetas: index.html, productos.html, nosotros.html, contacto.html, css/styles.css, images/.

# Tecnologías utilizadas en el proyecto

HTML5 semántico, CSS3 (variables, Flexbox, Grid, media queries), Google Fonts (Orbitron y Press Start 2P).

# Características implementadas

Lista breve: Flexbox (nav + footer), CSS Grid (hero/features/tarjetas), selectores de clase/ID/:hover/:nth-child, 3 breakpoints responsivos, accesibilidad básica (alt, aria-current).
